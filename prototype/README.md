# Prototype

Interactive React/Vite prototype for JIGo Travel Planner (CodeNection 2026).

## Quick start (Windows)

1. Install [Node.js LTS](https://nodejs.org).
2. Double-click `start-prototype.bat`, or run:

```bash
npm install
npm run dev
```

3. Open http://localhost:5173

## Google Maps (optional)

Copy `.env.example` to `.env` and set `VITE_GOOGLE_MAPS_API_KEY`.
